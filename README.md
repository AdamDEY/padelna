# Padelna

Padelna is a social app for padel players in Tunisia: find and create matches at the right level, book courts, rate players and confirm scores. A player's level (1–7) and trust signals (confirmed scores, reputation) are the heart of the product.

The app is in English and French (it follows the phone's language, and Edit profile has a Language switch). Arabic, right-to-left, is planned.

## Stack

- [Expo](https://expo.dev) SDK 58, React Native 0.88, React 19, TypeScript (strict), Expo Router with typed routes
- [HeroUI Native](https://github.com/heroui-inc/heroui-native) styled with Uniwind (Tailwind CSS v4 for React Native)
- Supabase (auth, Postgres, realtime, storage) with TanStack Query
- i18next and `expo-localization` for translations
- iOS and Android only. HeroUI Native does not support web.

## Getting started

This is a development build, not Expo Go, so it needs Xcode (iOS) or Android Studio.

1. Install dependencies

   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env.local` and fill in the Supabase and Google sign-in values.

3. Build and run on the iOS Simulator (needed once, and again after any native dependency change)

   ```bash
   npm run ios
   ```

4. Next time, start Metro for the existing build

   ```bash
   npx expo start --dev-client
   ```

   Add `--clear` after changing `metro.config.js` or when styles look stale.

CocoaPods needs a UTF-8 locale (`LANG=en_US.UTF-8`).

## Project layout

| Path | What lives there |
| --- | --- |
| `src/app/` | Routes only (Expo Router). Every file is a screen. |
| `src/components/` | Shared components, built on HeroUI. `Page` is the base of every screen. |
| `src/repositories/` | The only code that talks to Supabase. |
| `src/hooks/` | React Query hooks around the repositories. |
| `src/lib/` | Pure helpers (dates, level fit, scores, validation) and the Supabase client. |
| `src/i18n/` | Translations: `locales/en.ts` defines the keys, `locales/fr.ts` must match them. |
| `src/data/mock.ts` | Sample data for parts of the app that have no backend table yet. |
| `src/global.css` | Design tokens as HeroUI theme variables. |
| `supabase/migrations/` | Database schema, functions and policies. |
| `ios/` | Generated by Expo (CNG); change native settings in `app.json` and config plugins. |

Imports from `src` use the `@/` alias.

## Translations

All visible text goes through `t("area.key")` from `react-i18next`. Add the English text to `src/i18n/locales/en.ts` and the French to `fr.ts`; TypeScript flags a missing or misspelled key. The player's language is switched with `setLanguage()` from `@/i18n`.
